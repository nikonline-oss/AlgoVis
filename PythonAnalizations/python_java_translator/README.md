# ЯВА (Язык Визуализации Алгоритмов) - Транслятор Python кода

Транслятор Python кода в формат ЯВА (Язык Визуализации Алгоритмов) для визуализации алгоритмов.

## Возможности

- 📝 **Трансляция Python кода** в формат ЯВА JSON
- 🔧 **Модульная архитектура** с поддержкой пользовательских модов
- 👁️ **Конфигурируемая визуализация** - контроль над отображаемыми шагами
- ✅ **Валидация** - проверка корректности выходного JSON
- 🧩 **Расширяемость** - поддержка пользовательских алгоритмов и структур данных
